# Java Calculator Application

## Project Overview
An academic software project developed using Java as part of the Object-Oriented Programming course during the second academic level of the Information Technology program.

The project involves developing a graphical calculator application inspired by traditional calculators, allowing users to perform basic arithmetic operations through an interactive graphical user interface (GUI).

## Project Objectives
- Apply object-oriented programming concepts using Java.
- Gain practical experience in developing software applications.
- Understand how to design graphical user interfaces.
- Connect user interface components with application logic.
- Handle user inputs and display calculation results.

## Features
- **Addition:** Perform basic addition operations.
- **Subtraction:** Perform basic subtraction operations.
- **Multiplication:** Perform basic multiplication operations.
- **Division:** Perform basic division operations.
- **Graphical User Interface:** A calculator interface inspired by traditional calculators.
- **User Input Handling:** Process user inputs through interactive buttons.
- **Result Display:** Display calculation results clearly.

## Technologies Used
- **Programming Language:** Java
- **Development Environment:** Apache NetBeans IDE
- **GUI:** Java Graphical User Interface Components

## Project Information
- **Project Type:** Academic Project
- **Course:** Object-Oriented Programming
- **Academic Program:** Information Technology
- **Academic Level:** Second Level
- **Team Size:** Individual Project

## My Role
Designed the calculator interface and implemented the programming logic required to perform arithmetic operations. Also connected the graphical user interface components with the underlying calculation logic.
